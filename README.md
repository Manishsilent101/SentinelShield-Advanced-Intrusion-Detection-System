# SentinelShield - Advanced Intrusion Detection & Web Protection System

## Overview

SentinelShield is a Flask-based Web Application Firewall (WAF) simulation developed to detect and block common web-based attacks.

## Features

* SQL Injection Detection
* Cross-Site Scripting (XSS) Detection
* Local File Inclusion (LFI) Detection
* Directory Traversal Detection
* Command Injection Detection
* Brute Force Detection
* Attack Logging with Timestamp and IP Address
* Dashboard Analytics
* Recent Attack Logs Monitoring

## Technologies Used

* Python
* Flask
* HTML
* CSS
* VS Code

## Project Architecture

User → Flask Web Interface → Request Inspection → Detection Engine → Logging System → Dashboard
